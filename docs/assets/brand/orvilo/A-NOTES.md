# A: restrained relief

Orvilo-A.icon was created through Icon Composer MCP from the existing mark.svg. Both path geometries are unchanged and remain separate SVG assets.

Default: white background, graphite foreground. Dark: black background, near-white foreground. Glyph scale 0.90. Glass enabled; specular disabled; translucency disabled; neutral shadow opacity 0.04.

Apple ictool rendered a-light.png and a-dark.png for macOS, and a-preview-1024.png is the MCP preview. This is an approximation of the selected Image Gen PNG concept; native rendering has stronger tonal shading. No application resource replacement or installed-app validation is included.

Image Gen concept files are PNG bitmaps. The SVG source was manually reconstructed earlier; it was not generated as SVG by Image Gen and is not a lossless vectorization of that PNG.
