# Lighter Orvilo Apple icon explorations

Four alternatives made using Icon Composer MCP and rendered by Apple ictool for macOS. All preserve the same two-path symbol with separate editable transparent SVG layers. Backgrounds and materials are Composer settings.

- 01-warm: warm ivory, graphite, flat foreground (glass disabled), scale 0.78.
- 02-mist: cool off-white, slate, specular enabled, no shadow, scale 0.78.
- 03-blue: pale blue, muted blue, specular and mild translucency, no shadow, scale 0.78.
- 04-air-dark: softened charcoal, ivory, no specular or shadow, scale 0.70.

These are visual alternatives, not installed application assets. Native Icon Composer UI inspection and installed-app acceptance remain pending. The original Orvilo.icon is preserved.
