---
title: Personal WeChat integration
description: Connect a Patchbay agent to personal WeChat with Tencent iLink QR authorization.
---

## Requirements

- A personal WeChat account. No company, WeCom organization, Official Account, or developer AppID is required.
- A Patchbay workspace owner/admin, or ownership of the target agent.
- Self-hosted deployments: `PATCHBAY_WEIXIN_SECRET_KEY`, generated with `openssl rand -base64 32`.

## Connect

1. Open **Agents**, select the agent, then open **Integrations**.
2. Choose **Connect WeChat** and scan the QR code with WeChat.
3. Confirm in WeChat. If WeChat displays a verification code, enter it in the dialog.

The scanning WeChat identity is linked to the current Patchbay user automatically. Other workspace members receive a 15-minute account-linking URL the first time they message the connected account.

The adapter uses Tencent's native iLink HTTP JSON protocol directly: QR authorization, durable `getupdates` long polling, and `sendmessage` replies. Bot tokens and per-conversation context tokens are encrypted at rest. The current release supports direct text conversations only; group and media support are not advertised.

Disconnecting stops polling but keeps Patchbay chat history. Reconnecting the same account resumes from its durable cursor; replacing it with another account retires the old account bindings and routing state.
