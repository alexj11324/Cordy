Patchbay ワークスペースに Feishu Bot をインストールすると、チームメンバーは Feishu から DM を送る、グループで @メンションする、`/issue` でイシューを作成するといった操作ができます。会話と Agent イベントは引き続き Patchbay ワークスペースに保存されます。

インストールは特定のコンピューターや 1 つのエージェントには紐づきません。メンバーは会話中に `/agents` でエージェントを選択・切り替えます。別の Bot アイデンティティが必要な場合だけ専用インストールを追加してください。

## Bot を接続する

ワークスペースの owner と admin が接続を開始できます。

1. **Settings → Integrations** を開き、**Feishu に接続**をクリックします。
2. ワークスペース単位のインストールを選択します。
3. Feishu で QR コードをスキャンし、認証を承認します。
4. Patchbay に戻ります。画面に **Feishu に接続済み**と表示されたらワークスペースで利用できます。

QR コードは 1 回限りの認証情報です。期限が切れた場合は再生成してください。接続済みのエージェントにはスキャン画面は再表示されません。名前や権限を変更する場合は、**Feishu で管理**をクリックします。

<Callout type="info">
現在、新規接続を利用できるのは中国本土版の Feishu だけです。既存の国際版 Lark 接続は、引き続き利用および管理できます。
</Callout>

## 初回利用

メンバーが初めて Bot にメッセージを送ると、アカウント連携用のリンクが届きます。

1. リンクを開き、Patchbay にログインします。
2. 紐づけるワークスペースのアカウントを確認します。
3. Feishu に戻り、もう一度メッセージを送ります。

連携が完了すると、Patchbay はメッセージを送ったワークスペースメンバーを特定できるようになります。ワークスペースのメンバーではないユーザーは Bot を利用できません。

## Feishu から仕事を依頼する

### DM

Bot にそのままメッセージを送ります。後続のメッセージは同じ Patchbay のチャットセッションに保持され、エージェントの返信も現在の DM に返されます。

### グループチャット

Bot をグループへ追加し、`@Bot` に続けて依頼内容を入力します。Bot が応答するのは、明示的に @メンションされたメッセージだけです。実行時には、現在のセッションで読み取れる直近のコンテキストも利用します。

### イシューを作成する

次のように送信します。

```text
/issue ログイン後のリダイレクトを修正する
Safari ではログインに成功してもログイン画面に残ります。
```

1 行目がタイトルになり、残りの内容が説明になります。`/issue` だけを送信した場合、Patchbay は直前のメッセージをタイトルとして使おうとします。

## 接続を管理する

**設定 → 連携**を開くと、ワークスペースに接続済みの Bot を確認できます。ワークスペースの owner と admin はここから接続を解除できます。エージェントの所有者は、そのエージェントの**連携**ページから自分の Bot を管理できます。

接続を解除すると、Bot は新しいメッセージを受信しなくなります。既存の会話と監査記録は削除されません。

## セルフホスト設定

Patchbay Cloud では追加設定は不要です。セルフホスト環境はサーバー管理で、アプリは読み取り専用になり Bot の認証情報を受け取りません。[セルフホストのメッセージングデプロイ契約](/self-host-messaging)に従い、サーバーでセットアップヘルパーを実行してください。

```dotenv
PATCHBAY_LARK_SECRET_KEY=<base64-encoded 32-byte key>
```

次のコマンドで生成できます。

```bash
openssl rand -base64 32
```

`PATCHBAY_MESSAGING_BOOTSTRAP=true` とサーバー所有のワークスペース/インストーラー ID、Lark の認証情報をシークレットストアに登録してから API サービスを再起動します。このキーは継続して保管してください。セルフホストのアプリには接続ボタンは表示されません。

`PATCHBAY_LARK_HTTP_BASE_URL` と `PATCHBAY_LARK_CALLBACK_BASE_URL` は、プロキシやテストなどの特殊な環境でのみ使用します。通常は設定する必要はありません。

## よくある問題

- **接続ボタンが表示されない**: 現在のアカウントがエージェントの所有者、ワークスペースの owner、admin のいずれかであることを確認します。セルフホストの場合は暗号化キーも確認してください。
- **QR コードの期限が切れた**: ダイアログを閉じて、接続をもう一度開始します。
- **Bot からアカウント連携を求められる**: 連携用リンクを開き、そのワークスペースで使う Patchbay アカウントにログインします。
- **Bot が実行しない**: エージェントがアーカイブされていないことと、使用する[ランタイム](/daemon-runtimes)がオンラインであることを確認します。
